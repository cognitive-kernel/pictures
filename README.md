# Pictures — نمایش تصاویر کالاهای راهکاران

برنامه PHP برای مشاهده کالاها و تصاویر پیوست آن‌ها از SQL Server راهکاران.

## امکانات
- اتصال PDO به SQL Server با تنظیمات محلی؛ رمز عبور در مخزن ذخیره نمی‌شود.
- فهرست کالاها با صفحه‌بندی سمت سرور، ۲۵ رکورد در هر صفحه.
- مرتب‌سازی امن بر اساس شماره و نام کالا.
- جستجوی سمت سرور بر اساس کد یا نام کالا و فیلتر روی داده‌های حاصل از کوئری پیوست‌ها؛ تعداد نتایج و صفحه‌بندی با فیلترها هماهنگ است.
- نمایش تصویر بندانگشتی و باز کردن تصویر در لایت‌باکس بدون بارگذاری مجدد صفحه.
- رابط فارسی و راست‌چین، واکنش‌گرا و مناسب موبایل.
- ثبت خطا در لاگ سرور بدون نمایش اطلاعات حساس اتصال.

## نیازمندی‌ها
- PHP 8.1 یا جدیدتر
- Apache و افزونه‌های PHP `pdo_sqlsrv` و `sqlsrv`
- دسترسی شبکه از وب‌سرور به SQL Server

## راه‌اندازی در XAMPP (Windows)
1. فایل `config/database.local.php.example` را به `config/database.local.php` کپی کنید.
2. مقادیر سرور، دیتابیس، نام کاربری و رمز را در فایل محلی تنظیم کنید. این فایل در Git نادیده گرفته می‌شود.
3. مطمئن شوید افزونه `pdo_sqlsrv` برای نسخه PHP نصب و فعال است.
4. آدرس `http://localhost/pictures/` را باز کنید.

## ساختار دیتابیس مورد انتظار
- کالاها: `[SLS3].[Product]` با ستون‌های `ProductID`, `Number`, `Name`
- پیوست‌ها: `[SLS3].[ProductAttachment]` با ستون‌های `ProductRef`, `FileContent`

منبع اصلی گالری، کوئری پیوست‌هاست: `[SLS3].[ProductAttachment]` با اتصال به `[SLS3].[Product]` و `[LGS3].[Part]`. بنابراین فقط کالاهایی در گالری قابل نمایش‌اند که در منبع پیوست‌ها رکورد داشته باشند؛ کالاهایی که هیچ رکورد پیوستی ندارند از این کوئری قابل شناسایی نیستند. مرورگر فقط فرمت‌های تصویری رایج را نمایش می‌دهد.

## امنیت
- فایل `config/database.local.php` را هرگز commit نکنید.
- برای این برنامه از حساب SQL فقط‌خواندنی با حداقل دسترسی لازم استفاده کنید.
